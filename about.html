Who We Are

We are a small web development project created to demonstrate server-side routing using Node.js.

The server uses Node.js's built-in HTTP module to receive requests and send appropriate HTML pages as responses.

Simple

The project uses simple Node.js concepts that are easy to understand.

Fast

Node.js can handle HTTP requests efficiently using its event-driven architecture.

Educational

This project helps beginners understand routing and HTTP responses.
